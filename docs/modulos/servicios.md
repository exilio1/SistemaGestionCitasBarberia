# Servicios

El módulo de servicios maneja el catálogo de lo que ofrece la barbería. Desde aquí se pueden agregar nuevos servicios, actualizar precios o desactivar los que ya no se ofrecen.

---

## Lista de servicios

La tabla muestra todos los servicios con su nombre, descripción, precio, duración estimada y estado.

---

## Agregar o editar un servicio

El formulario pide el nombre del servicio, una descripción de lo que incluye, el precio y la duración estimada en minutos. La duración es importante porque el sistema la usa para calcular la disponibilidad en la agenda.

Si se cambia el precio de un servicio, ese cambio aplica solo para las citas nuevas. Las citas anteriores mantienen el precio que tenían cuando se registraron.

---

## Desactivar un servicio

Los servicios inactivos no aparecen disponibles al registrar nuevas citas, pero el historial de citas anteriores que usaron ese servicio se conserva sin cambios.
