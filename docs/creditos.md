## Tecnologías y herramientas utilizadas

- **Python 3.12** — lenguaje principal
- **CustomTkinter** — interfaz gráfica de escritorio
- **SQLite** — base de datos local
- **python-telegram-bot** — integración con Telegram
- **bcrypt** — cifrado de contraseñas
- **ReportLab** — generación de PDFs
- **PyInstaller** — empaquetado del ejecutable
- **GitHub Actions** — integración y despliegue continuo
- **GitBook** — documentación del proyecto
